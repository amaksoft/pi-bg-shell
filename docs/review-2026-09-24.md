## Major (10)

- **Unvalidated `parseInt` on exit files** (`src/runtime.ts`, `waitForExitCode`
  + `readExitCodeFile`). A torn/partial write yields `NaN`: foreground throws
  `exited with code NaN`; poller treats `NaN !== undefined` as completed and
  sends a `NaN` completion. The watcher path already guards with `/^-?\d+$/`.
  Fix: same guard (or `Number.isInteger`) on all three paths; treat garbage as
  not-ready, not exit-0/NaN.
- **Predictable `/tmp` spool root** (`config.ts:127`, `runtime.ts:140-160`).
  `outputDir` defaults to `/tmp/pi-tmux-bash`, leaf only is random, recursive
  mkdir follows symlinks. Fix: `O_NOFOLLOW`/lstat ownership check on the root,
  or default under `~/.pi/agent/` (XDG-style), document the threat.
- **Unbounded registry + log growth** (`src/runtime.ts`). Neither natural
  completion path calls `forgetJobsForWindow`; `.out` files are full-fidelity
  with truncation display-only. Fix: forget on completion (keep a bounded
  recently-completed cache if claudify needs it), cap log dir size/count, note
  retention in the contract.
- **Stale `pi-tmux-bash` wire identity** (`tmux-utils.ts:23-27`, `config.ts`,
  `renderers/messages.ts`). Window options, `/tmp` default, `tmux-bash.jsonc`,
  `tmux-bash-poll/completion` types, default session names — old and new forks
  share sessions and collide. Fix: rename to `bg-shell` namespace with a
  migration note, or document intentional-compat (sharing sessions across forks
  is a footgun either way; choose explicitly).
- **Vendored code without provenance** (`vendor/`). No origin/commit/version
  headers; drift undetectable. Fix: header each file with repo + commit hash +
  date, add `vendor/README.md`.
- **Dead upstream paths in tests** (`tests/testing/pi-test-utils.ts:72`,
  e2e headers). Harness resolves `extensions/tmux-bash/src/index.ts`, which
  does not exist here (`pi.extensions` is `./src/index.ts`). Fix paths or the
  parity suites stay stale even where tmux exists.
- **Unrunnable e2e gap is unmitigated** (`tests/`). e2e/interactive/parity boot
  real pi + tmux unconditionally; no skip guard, no `vitest` project split,
  bare `vitest --run` runs everything. Fix: split unit vs e2e projects,
  `PI_E2E=1` gate with skip-by-default, so `bun run test` is green anywhere.
- **Test gaps (each confirmed, grouped):** poll-path completion enrichment;
  `pollDelivery` model/display branches + clamp + idle-retry; foreground
  streaming helpers; Ctrl+B handler invocation (only registration asserted);
  `/tasks` kill-success path; reaper dead-window kill branch; shutdown hook
  ordering (all unit mocks discard `pi.on` handlers); non-git `runBashInTmux`
  path. Highest value first: NaN-guard test, kill-success, shutdown ordering,
  reaper-kills-dead (can stage a dead pane with `remain-on-exit`).

## Appendix: batch delivery + live overlay (session 01a0e8b2)

- Forensics (spool `.consumed` mtimes vs transcript): all 10 exits landed
  within ~2s, but per-tick-only batching delivered the first two as
  singletons 7s apart (adjacent ticks + pi serializing the second
  follow-up behind the first model turn). Fix: backlog-aware coalescing —
  ticks PEEK (no consume), hold while peers run (default 2500ms), flush on

  immediate delivery.

  scroll offset, kill-arm; elapsed ticks, completions appear/disappear,
  detail tails grow). Timer stops on close; headless path untouched.
